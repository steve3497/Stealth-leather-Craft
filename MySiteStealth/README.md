# Stealth Leather Craft India

Static site for a handmade leather goods brand.

Stack: HTML · CSS · Vanilla JS  
Deploy: GitHub Pages

## Pages

- `index.html` — Home
- `pages/collection.html` — Collection
- `pages/about.html` — About
- `pages/contact.html` — Contact

## Local preview

Open `index.html` in a browser, or serve the folder with any static server.

## Before you publish

1. Replace `YOUR-USERNAME` in canonical URLs, `robots.txt`, and `sitemap.xml`
2. Add product photos and a workshop photo using the paths in `IMAGE_ASSETS.txt`
3. Fill WhatsApp, Instagram, email, and `[CONTENT TO BE PROVIDED]` copy

Missing photos render as labeled placeholders.
